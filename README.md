# LaunchPad (Failfolio-DB)

**Share. Learn. Launch Better.**

A community-driven platform where founders share failed and successful startup ideas, browse them by category, and learn from real outcomes before building their next venture.

🔗 **Live Demo:** [fail-fast-db-rnpq.vercel.app](https://fail-fast-db-rnpq.vercel.app/)

## About

LaunchPad (internally built as Failfolio-DB) is a full-stack web app for founders to document and explore startup ideas across categories like EdTech, FinTech, HealthTech, AgriTech, and more. The goal is to turn failed ideas into a shared learning resource instead of a private lesson — and to help people sanity-check new ideas against what's already been tried.

## Features

- Browse startup ideas across multiple industry categories (EdTech, E-Commerce, HealthTech, FinTech, Logistics, AgriTech, Travel, GovTech, Retail, Transport, Media)
- Community feed for sharing project ideas and outcomes
- "Analyze Idea" tool for getting feedback/predictions on a new venture before building it
- User sign-up and profile system

## Tech Stack

- **Frontend:** Next.js
- **Backend:** Flask
- **Database:** MySQL
- **Deployment:** Vercel

I'm continuing to dig deeper into the backend logic and database design as I extend this project.

## Getting Started

```bash
# Clone the repo
git clone https://github.com/zainab-stack9050/Failfolio-DB.git

# Install frontend dependencies
cd Failfolio-DB
npm install

# Run the development server
npm run dev
```

Set up your Flask backend and MySQL database connection according to the config files before running the full stack locally.
